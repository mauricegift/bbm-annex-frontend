# BBM Annex Frontend

  > ⚠️ **This project has been upgraded and moved.**
  >
  > BBM Annex has evolved into the full **SBE Annex** academic platform, now hosted as a structured monorepo.
  >
  > 👉 **New repository:** [github.com/mauricegift/sbe-annex](https://github.com/mauricegift/sbe-annex)

  ---

  ## What Changed

  | Before | After |
  |---|---|
  | BBM-only (Business Management) | Full SBE (School of Business & Economics) |
  | Frontend-only repo | Monorepo with `backend/` + `frontend/` |
  | Manual super admin setup | First registered user becomes Super Admin |
  | Static CORS config | Dynamic CORS from `CORS_ORIGINS` env var |
  | GitHub CDN profile pictures | Base64 profile pictures (no CDN dependency) |
  | Register with fixed fields | Dynamic groups from API, phone optional |
